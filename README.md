# EcoTrack – Smart Waste Collection Management System

## Run Backend
cd EcoTrack/backend
npm install
npm run seed
npm start

## Run Frontend (new terminal)
cd EcoTrack/client
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000
MongoDB: mongodb://127.0.0.1:27017/EcoTrack
